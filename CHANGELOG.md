# Changelog

## 0.2.0 - 2026-10-05

Editable browser lab runs the same Prolog rules in a dedicated WebAssembly
worker. Adds irrelevant-evidence, plausible-fabrication and missing-owner
fixtures, WASM/native parity tests, bounded JSON input, download/reset controls,
stale-result handling and third-party runtime notices. No evidence-quality or
decision-quality claim follows from passing a structural report.

## 0.1.0 - 2026-10-05

First experimental release: reasoning-record checker, finite refutability
witness, six fictional fixtures, 35 rule tests, CLI regressions, nine Mermaid
charts, a field guide with ten exercises, consulting/coaching/WWZS? prompts,
conceptual essay, evaluation protocol, noncommercial licensing and polemic.

Includes a static publication package for `/zizkian/`. No efficacy benchmark,
trained weights, automatic model dispatcher or truth-certification claim.
