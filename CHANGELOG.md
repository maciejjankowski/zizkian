# Changelog

## 0.3.0 - 2026-10-06

Validate JSON strings and Booleans before conversion through a shared strict
native/WASM entry point. Reject duplicate keys, trailing commas, literal control
characters, a BOM, invalid UTF-8 bytes and invalid surrogate escapes. Bound raw browser input so
shadowed duplicate values cannot bypass depth or array limits. Terminate pending
workers on reset and provide recovery without discarding edits.

Passing verdicts now ask for review of the declared test, change or closure.
Every report carries its scope, schema version, unverified-evidence flag and
human-review requirements. Input fields remain unchanged; see the checker's
migration table. Add a generated versioned shape schema, typing/syntax regressions,
worker-lifecycle tests and an unasked-coaching consent regression. The method now
discloses encoded versus human responsibilities and includes a concrete return-cut
worksheet. Keep the matrix essay as a separate historical appendix.
Use vertical proof and inquiry diagrams, compact branch maps and readable chart
labels by default. Wide charts scroll inside their panels; overview fitting is
an explicit control rather than automatic shrinking.

## 0.2.0 - 2026-10-05

Editable browser lab runs the same Prolog rules in a dedicated WebAssembly
worker. Adds irrelevant-evidence, plausible-fabrication and missing-owner
fixtures, WASM/native parity tests, bounded JSON input, download/reset controls,
stale-result handling and third-party runtime notices. No evidence-quality or
decision-quality claim follows from passing a structural report.

## 0.1.0 - 2026-10-05

First experimental release: reasoning-record checker, finite refutability
witness, six fictional fixtures, 35 rule tests, CLI regressions, nine Mermaid
charts, a field guide with ten exercises, consulting/coaching/WWZS? prompts,
conceptual essay, evaluation protocol, noncommercial licensing and polemic.

Includes a static publication package for `/zizkian/`. No efficacy benchmark,
trained weights, automatic model dispatcher or truth-certification claim.
