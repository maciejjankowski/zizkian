The method

The unit is a reading: a proposed interpretation of a question, observation or arrangement. A reading is not a discovered motive merely because it is memorable.

The operator

  1. Preserve the user’s strongest intended question and desired result.
  2. Name the decision owner and real constraints.
  3. State the strongest ordinary explanation before offering an inversion.
  4. Select a small relevant set of lenses. Each must contribute a distinct question.
  5. Offer a rejectable hypothesis and identify supporting observations separately.
  6. Specify the observation that would defeat the reading and how to obtain it.
  7. Apply the return cut to the analyst’s own framing and possible payoff.
  8. Produce an owned test, a supported decision change, or no finding and closure.

WWZS? is the provocation mode. It names a question-generating move, not a claim about what the philosopher would literally say. The falsification question is inherited from the project’s earlier conversations.

Invariants

Evidence is not traded against rhetorical force, votes or an attention weight. Participant refusal is not evidence of a hidden motive. Personal exploration requires invitation. A return cut can find nothing. A check can preserve the original brief. A defeated reading cannot remain active in the decision.

Consulting and coaching differ in authority. Business inquiry examines declared constraints, outcomes and observations. Coaching works with the participant’s chosen question and accepted next-step framing. Neither can grant an analyst privileged access to another person’s mind.

What the Prolog layer does

The checker validates a finite declared record. It checks shape and references before evaluating rules. Missing declared support blocks supported; it does not prove support absent from the world. A defeated test declaration on an active reading yields defeated_reading. Explicit untested statuses preserve unknowns.

The program audits a snapshot. It does not interview a participant, read a source, run an experiment or automatically update the epistemic status of a reading.

No compulsory depth

A tutorial can be good instruction. An approval boundary can reflect a real risk. A stalled handoff can reflect understaffing. When the ordinary explanation survives, retain it. Stop recursion when another pass changes no test or decision.

The matrix

The attention matrix records authored priorities across eight dimensions. It is an illustration, not a calibrated operator. The working checker never reads it. The essay preserves the Hamiltonian analogy as architectural metaphor, with no claims of physics or numerical diagnosis.

If that hypothesis is wrong, the earliest signal is additional complexity and suspicion with no stronger evidence, useful test or participant-owned action. See evaluation.
